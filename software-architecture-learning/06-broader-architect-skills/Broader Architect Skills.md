# 06 Broader Architect Skills

- **Security Architecture:** OAuth2, JWT, Azure AD, Zero Trust.
- **DevOps & CI/CD:** Pipelines, Infrastructure as Code (Terraform, Bicep).
- **Scalability & Performance:** Caching (Redis), load balancing, DB optimization.
- **Documentation & Communication:** C4 model diagrams, ADRs (Architecture Decision Records).
- **Capstone Project:** Design a complete system blueprint (e.g., online learning platform).
